## 一句话介绍

ANE（AI Native Engineering，AI 原生工程）是一套面向 AI Agent 时代的**通用软件工程范式**。它把软件视为"数字生命体"，用确定性骨架约束概率性智能，让"可证明的交静态、不确定的交智能、触底线的交人类"。它不绑定任何具体产品、框架或工程实现，适用于一切构建 AI 原生软件系统的团队。

三条护城河：**小脑优先**（高频决策零 Token）· **记忆升格**（大脑顿悟变小脑本能）· **双轨免疫**（符号轨 + 统计轨同时通过才放行）。

### v0.8.0 五项新增与四项修复（v0.7.0 归档见下）

1. **模型载体治理（5.6）** — 选型六判据 · 强制模型卡 · 升级退役门禁 · 载体可替换且不成为架构依赖。
2. **提示词资产治理（18.4）** — 模板版本化与稳定 ID · 冻结术语接口 · 注入防护 · 变更评测与回滚。
3. **事件响应与无责复盘（21.5）** — 把"异常当轮上报"接成"检测→遏制→根因→恢复→复盘→经验升格"闭环；隐瞒与篡改台账才是红线。
4. **ISO 42001 实质对齐（20.2）** — 补上此前仅在摘要声明、正文无展开的管理体系七要素对照表。
5. **NTP 超时与去重参数（5.5）** — 按 D 级设定超时区间、同源合并窗口、上行次数上限与冷却窗口；超时一律走 DEGRADED。
6. **仲裁可观测三指标（12.1）** — 配额耗尽率 / 被打回率 / D0-D1 抢占率，使仲裁公平性可被审计。

修复四类问题：三处交叉引用错位（升格审计→24.3、双脑极限态→21.3b）、一处小节名实不符、三处过时"本轮新增"标签，以及 NTP 载荷示例（5.2 / 5.4）的可解析性——三个示例现均为合法 JSON，枚举全集与字段说明移入逐字段释义表，环境变量改为抽象档位取值，下行候选只传 `candidate.digest` 指纹而不内联正文，从协议层保证"大脑不直接落地"。

### v0.6.0 四组增强（已归档）

1. **演进速度五步算法（10.4）** — 删除 → 简化 → 优化 → 加速 → 自动化，顺序不可颠倒；越级即"把负债流水线化"。
2. **执行纪律（10.5）** — 结构化上报（问题 / 已尝试 / 所需）· 异常当轮上报 · 高内聚融合 · 99% 即灰度。
3. **双脑硬边界与 NTP 高阶信道（4.4 / 5.3 / 5.4 / 5.5）** — 小脑三条硬边界（离网可用 / 可生长 / 零推测）· 上行求救包与下行建议包 Schema · 四大铁律 · 通信状态机与信道仲裁 · 探索/利用限频。
4. **双脑极限态（21.3b）** — 大脑不可达退入纯小脑 L2；记忆污染冻结升格、退化为无记忆；两者都不允许"带病求助"。

### v0.5.0 五项增强（已归档）

1. **冷启动与知识冷淬火（6.4）** — 种子规则灌入 + explore/exploit 自适应切换，解决"上线首日空记忆成本失控"。
2. **硬件拓扑感知（2.3 / 8.5）** — 统一语义层按处理器能力、加速单元数、内存与存储特性自适应优化。
3. **国内法规对齐（20.2）** — 对齐《数据安全法》《个人信息保护法》、等保 2.0 三级，阐明人类主权与防自欺如何满足"可追溯、可控"。
4. **双折叠协同模式（13.4 / 14.3）** — 折一判定层（认知摘要）+ 折二授权层（意图绑定）的人机协同强制范式，及其原语编码。
5. **升格审计（24.3）** — 经验升格的连续 N 次独立复现 + 人类签名背书 + 反近亲繁殖检验，防记忆升格投毒。

## 核心理念

- **动静结合**：静态是基石，动态是灵魂；动中有静，静中有动。
- **开发维护一体**：运行即感知，感知即维护，维护即开发，开发即进化。
- **稳态第一，变异受控**：一切 AI 变异须经免疫门禁，人类始终握有最终主权。
- **全景白盒，拒绝静默**：任何结论都可回放、可审计，静默失败等于零。
