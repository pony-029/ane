## 一句话介绍

ANE（AI Native Engineering，AI 原生工程）是一套面向 AI Agent 时代的**通用软件工程范式**。它把软件视为"数字生命体"，用确定性骨架约束概率性智能，让"可证明的交静态、不确定的交智能、触底线的交人类"。它不绑定任何具体产品、框架或工程实现，适用于一切构建 AI 原生软件系统的团队。

三条护城河：**小脑优先**（高频决策零 Token）· **记忆升格**（大脑顿悟变小脑本能）· **双轨免疫**（符号轨 + 统计轨同时通过才放行）。

### v0.6.0 四组增强

1. **演进速度五步算法（10.4）** — 删除 → 简化 → 优化 → 加速 → 自动化，顺序不可颠倒；越级即"把负债流水线化"。
2. **执行纪律（10.5）** — 三句话沟通（难题 / 已试 / 所需）· 坏消息不过夜 · 一体化压铸 · 99% 即灰度。
3. **双脑硬边界与 NTP 高阶信道（4.4 / 5.3 / 5.4 / 5.5）** — 小脑三条硬边界（离网可用 / 可生长 / 零推测）· 上行求救包与下行建议包 Schema · 四大铁律 · 通信状态机与信道仲裁 · 探索/利用限频。
4. **双脑极限态（21.3b）** — 大脑不可达退入纯小脑 L2；记忆污染冻结升格、退化为无记忆；两者都不允许"带病求助"。

### v0.5.0 五项增强（已归档）

1. **冷启动与知识冷淬火（6.4）** — 种子规则灌入 + explore/exploit 自适应切换，解决"上线首日空记忆烧钱"。
2. **硬件拓扑感知（2.3 / 8.5）** — 中间表示层按指令集、加速核数、内存带宽自适应编译排优。
3. **国内法规对齐（20.2）** — 对齐《数据安全法》《个人信息保护法》、等保 2.0 三级，阐明人类主权与防自欺如何满足"可追溯、可控"。
4. **双折叠协同模式（13.4 / 14.3）** — 折一判定层（认知摘要）+ 折二授权层（意图绑定）的人机协同强制范式，及其原语编码。
5. **升格审计（17.2 / 24.3）** — 经验升格的连续 N 次独立复现 + 人类签名背书 + 反近亲繁殖检验，防记忆升格投毒。

## 核心理念

- **动静结合**：静态是基石，动态是灵魂；动中有静，静中有动。
- **开发维护一体**：运行即感知，感知即维护，维护即开发，开发即进化。
- **稳态第一，变异受控**：一切 AI 变异须经免疫门禁，人类始终握有最终主权。
- **全景白盒，拒绝静默**：任何结论都可回放、可审计，静默失败等于零。
